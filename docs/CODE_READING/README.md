# 코드 단위 해설 시리즈

실제 코드를 블록별로 붙여놓고 한 줄씩 해설한다. 실행 순서대로 읽으면 된다.

## 읽는 방법

각 편은 이런 구조다.

1. **이 파일이 푸는 문제** — 왜 존재하는가
2. **블록별 해설** — 코드 원문 + 줄 단위 설명 + "왜 이렇게 했나"
3. **가져갈 것** — 다른 프로젝트에도 재사용 가능한 패턴
4. **실습** — 손으로 확인해볼 명령 (대부분 `FDM_BACKEND=mock`으로 LLM 없이 가능)

> ⚠️ 표시가 있는 곳은 **이 프로젝트의 알려진 약점**이다. 그대로 믿지 말고,
> 왜 약점인지 이해한 다음 개선 과제로 삼으면 된다.
